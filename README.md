## Установка и запуск

Требуется Python 3.10 или новее.

В терминале из папки проекта:

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Формат Excel

Программа ожидает два листа.

### Лист «Работы»

Обязательные столбцы:
- `Класс`
- `Фамилия`
- `Имя`
- `Вариант`
- `1`, `2`, `3`, ..., `10`

Дополнительные столбцы `Литера` и `Отчество` поддерживаются и есть в шаблоне.

### Лист «Ключи»

Обязательные столбцы:
- `Вариант`
- `1`, `2`, `3`, ..., `10`

Вариант из листа «Работы» должен иметь соответствующую строку на листе «Ключи».
Все десять ключей каждого используемого варианта должны быть заполнены.

## Алгоритм

Каждый ответ сравнивается с ключом после удаления внешних пробелов и приведения к нижнему регистру.
Совпадение даёт 1 балл, несовпадение — 0, пустой ответ учитывается как пропуск.

Это учебная упрощённая проверка. Она не заменяет официальные критерии ОГЭ.
Если конкретное задание допускает несколько корректных форм записи, алгоритм необходимо расширить.
Автоматические результаты следует выборочно сверять с исходными работами.

4. Проанализировать диаграмму успешности.
